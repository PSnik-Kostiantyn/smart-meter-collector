# Результати тестів

Усі вимірювання зроблено 25.11.2026 на одному ноутбуці з 8 логічними ядрами.
Емулятори, брокер, колектор і InfluxDB працювали на ньому одночасно.

| Файли | Тест |
|---|---|
| `functional_*` | 50000 повідомлень, 5% навмисно зіпсовані, звірка з InfluxDB |
| `load4_*` | 4 емулятори по 100000 повідомлень на максимальній швидкості, черга брокера 1000000 |
| `load4_lossy_*` | той самий тест із чергою брокера 100000, брокер скинув частину повідомлень |
| `step_test_x1_run1.csv`, `step_test_x1_run2.csv` | ступінчасте навантаження, одна копія колектора, два прогони |
| `step_test_x2.csv` | ступінчасте навантаження, дві копії колектора |
| `step_x*_*` | сирі журнали і підсумки емуляторів для ступінчастих тестів |
